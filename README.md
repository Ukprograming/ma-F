# 弾性力と物体の運動解析

動画上の2つの対象を追跡し、位置・速度・加速度とばねの弾性力を比較する教材です。

## 起動

`index.html` と `analysis-store.js` を同じフォルダーに置き、ブラウザーで `index.html` を開いてください。デモを使う場合は `demo_faststart.mp4` も同じフォルダーに必要です。Chart.jsをCDNから読み込むためインターネット接続が必要です。

ローカルサーバーで確認する場合：`python -m http.server 8086` を実行し、`http://localhost:8086` を開きます。

## 計測

1. 動画またはデモを開き、撮影時のFPSを入力します（初期値30）。
2. 基準長をメートルで入力し、「スケール設定」で動画上の既知の長さをドラッグします。
3. 「座標軸設定」で原点・軸の向きをドラッグして調整します。
4. 「計測開始」を押し、追跡対象を選んで物体をクリックします。自動送りが有効なら次のフレームへ進みます。
5. 「計測を停止」で記録を止められます。同じフレームを計測し直すと、その点を置き換えます。

計測開始後はスケール・基準長・座標軸の設定欄を非表示にします。停止しても非表示を維持し、全消去または新しい動画を開いたときに再表示します。この状態は解析保存・復元でも維持します。

ばね比較では、物体とばね端のトラック、ばね定数を指定してください。両トラックの同時刻の点が必要です。既存の計算方式を継承し、最初の対応点の距離を基準長として比較します。速度・加速度は局所二次回帰で求めます。半窓幅7なら前後7点ずつが必要で、点が足りない部分は計算できません。表では「—」で表示します。

## 保存と再開

- **解析保存**：2トラックの計測点・原点、スケール・座標軸、FPS、再生位置、ばね・回帰設定、グラフ種類と系列表示を `.ma-f.json` に保存します。
- **解析を開く**：保存したJSONを選びます。対応する動画が開かれていれば復元し、まだなら画面に表示される元動画を選択します。動画の名前・ファイルサイズ（保存時に取得できた場合）・長さ・解像度を照合します。これは内容のハッシュ照合ではありません。
- 動画自体はJSONに含まれません。**JSONと元動画を一緒に保管**してください。自動保存ではありません。保存ボタンの通知後は、ブラウザーのダウンロード先にファイルができたことを確認してください。
- 復元待ちは取り消せます。不正なJSONや異なる動画では現在の計測データを上書きしません。未保存の変更がある状態で切り替える場合は破棄の確認が出ます。キャンセル後に保存できます。
- **CSV**：指定した物体トラックの位置・速度・加速度・ばね力を出力します。**画像保存**：現在のグラフをPNGにします。

解析JSONはこのアプリ専用のバージョン1形式です。参考にした Video-Motion-Track のJSONとは互換ではありません。

## 画面操作

- PCでは動画とデータ欄の境界をドラッグして幅を調整できます。境界にフォーカスし、左右キーでも操作できます。
- 「グラフ拡大」で表示領域を広げ、「動画とデータに戻す」またはEscapeキーで戻ります。
- 動画下のスライダーで再生位置を移動できます。グラフのドラッグでも動画と同期します。
- 表は内部をスクロールでき、対応ブラウザーでは右下をドラッグして高さを変更できます。
- スマートフォンでは縦にスクロールし、保存・読み込み・CSVなどの操作も利用できます。

## 検証

`node --test analysis-store.test.cjs` でJSON往復、破損・範囲外データの拒否、アプリの構文を確認できます。ローカルブラウザーで保存・復元と狭幅の表示も確認しています。実機iPad・Chromebookや公開環境の動作確認は別途必要です。
